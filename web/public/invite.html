Tu es invité·e sur KPB Education

KPB Education accompagne les étudiants d'Afrique francophone : test d'orientation, universités et filières, bourses avec leurs échéances, et suivi de dossier avec un conseiller.

Ton code de parrainage

Code copié. Colle-le dans l'application.

  1. Télécharge l'application (boutons ci-dessous).
  2. Crée ton compte avec ton e-mail et complète ton profil.
  3. Après ton inscription, ouvre Profil → « Parrainer un ami » (écran Parrainage), puis saisis ce code sous « Tu as un code de parrainage ? ».

Télécharger l'application

Android — Google Play iPhone — App Store

Déjà installée ? Ouvre l'application, puis saisis le code ci-dessus dans l'écran Parrainage après ton inscription.
