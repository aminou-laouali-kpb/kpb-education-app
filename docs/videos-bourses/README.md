# Vidéos résumées des bourses (NotebookLM)

28 bourses ouvertes ou à venir, extraites du catalogue vérifié (`backend/src/modules/scholarships-index/data/`). Une fiche = une vidéo.

## Procédure

1. Ouvrir un nouveau notebook NotebookLM par bourse et y importer **un seul** fichier `.md`.
2. Générer un « Video Overview » en français (les consignes en tête de fiche cadrent le contenu).
3. Ajouter le logo KPB Éducation en bas à droite pour masquer le filigrane NotebookLM.
4. Mettre la vidéo sur YouTube (« non répertoriée » suffit) : l’admin n’accepte que des liens YouTube.
5. Admin → fiche de la bourse → section Vidéos : coller le lien, statut **publié**.
   Voir `docs/admin-videos-bourses.md` : une vidéo n’apparaît que si la fiche bourse elle-même est publiée.
